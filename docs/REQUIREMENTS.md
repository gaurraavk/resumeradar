# Backend Requirements Specification

| ID | Description | Source | Priority | Backend Impact | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **REQ-001** | **Candidate & Admin Authentication**: Support user registration, login, profile retrieval, password hashing, and admin role authentication with secure token generation. | PRD / Frontend Auth Screens | High | Auth routes, JWT/Token middleware, Password hashing service, User repository | Complete |
| **REQ-002** | **ATS Resume Analysis Engine**: Analyze candidate resume against target job description, score overall match (0-100), compute granular breakdown (keywords, experience, impact, ATS formatting), identify missing keywords with impact rating, extract found skills, and generate actionable recommendations. | PRD / `server.ts` / `AnalysisResultView` | Critical | `/api/v1/analyze` endpoint, Gemini prompt schema + fallback heuristic engine | Complete |
| **REQ-003** | **Resume Optimization & Bullet Rewriting**: Rewrite candidate resume to achieve top 5% ATS match (92-97 score), applying selected recommendations, incorporating missing keywords, and highlighting upgraded verbs. | PRD / `OptimizationComparisonView` | Critical | `/api/v1/optimize` endpoint, LLM prompt optimization pipeline + fallback heuristic optimizer | Complete |
| **REQ-004** | **Power Bullet Rewrite Studio**: Provide 3 distinct bullet point rewrites following Google XYZ formula, Executive/Leadership focus, and Deep Technical Precision with impact scoring and keywords. | Frontend `BulletRewriteStudio` | Medium | `/api/v1/rewrite-bullet` endpoint, structured AI prompting + heuristic fallback | Pending |
| **REQ-005** | **Tailored Cover Letter Generator**: Generate high-converting, 3-4 paragraph quantified cover letter tailored to candidate resume, job title, company name, and selected tone. | Frontend `CoverLetterGenerator` | Medium | `/api/v1/cover-letter` endpoint, structured AI generation + template fallback | Pending |
| **REQ-006** | **Interview Question Predictor**: Generate tailored technical, behavioral, and system design interview questions with STAR-method answer blueprints mapped to resume claims and job requirements. | Frontend `InterviewPredictor` | Medium | `/api/v1/interview-questions` endpoint, STAR-blueprint generator service | Pending |
| **REQ-007** | **ATS Parser Simulation & Formatting Audit**: Check resume parseability against major ATS engines (Workday, Greenhouse, Lever, Taleo), scoring compliance, font/section structure, and contact data extraction. | Frontend `AtsParserSimulator` | Medium | `/api/v1/ats-check` endpoint, ATS parsing compliance validator | Pending |
| **REQ-008** | **Resume & Target Job Library Persistence**: Allow users to create, list, view, update, and delete stored master resumes and target job descriptions. | Frontend `ResumesLibraryView` & `JobsLibraryView` | High | `/api/v1/resumes`, `/api/v1/jobs` CRUD endpoints and repository models | Pending |
| **REQ-009** | **Analysis History & Versioning**: Persist completed ATS scans, score benchmarks, applied recommendations, and versioned resume iterations per user. | Frontend `HistoryView` & `VersionHistoryModal` | High | `/api/v1/history` CRUD endpoints and history repository | Pending |
| **REQ-010** | **LinkedIn OAuth 2.0 & Job Radar Matching**: Support live LinkedIn OAuth redirect/popup flow with simulation fallback, profile data import, and real-time skill matching against live LinkedIn jobs feed. | PRD / `LinkedInRadarView` / `server.ts` | High | `/api/v1/auth/linkedin/url`, `/auth/callback`, `/api/v1/linkedin/profile`, `/api/v1/linkedin/match-jobs` | Pending |
| **REQ-011** | **Admin Governance, Quota & Telemetry**: Provide super administrators with metrics dashboard, registered user management (status toggling, quota increments), scan audit logs, AI engine status, and security telemetry. | Frontend `AdminDashboardView` | High | `/api/v1/admin/overview`, `/api/v1/admin/users`, `/api/v1/admin/users/:id/*`, `/api/v1/admin/logs`, `/api/v1/admin/system` | Pending |
| **REQ-012** | **System Health & Diagnostic Endpoints**: Provide health checks for automated uptime monitoring, Gemini API availability, and memory usage. | Architecture | Medium | `/api/v1/health`, `/healthz` endpoints | Pending |
| **REQ-013** | **Security & Input Validation**: Sanitize all incoming payloads, enforce rate limits, prevent injection, guard sensitive credentials, and protect object-level authorization. | Security Policy | Critical | Request validators, rate limiter middleware, error handler middleware | Pending |
